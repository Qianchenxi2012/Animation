CuSO₄ 与 NaOH 的反应

concentration  /  stoichiometry  /  precipitate

等待加入试剂
反应原理

硫酸铜溶液与氢氧化钠溶液反应，生成氢氧化铜蓝色沉淀。这是检验铜离子常用的反应。

CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄

碱不足时还会生成碱式硫酸铜；碱过量且浓度高时，沉淀继续溶解成深蓝色的四羟基合铜配离子：

2CuSO₄ + 2NaOH → Cu₂(OH)₂SO₄↓ + Na₂SO₄
Cu(OH)₂ + 2NaOH ⇌ [Cu(OH)₄]²⁻
浓度决定产物
n(OH⁻) : n(Cu²⁺)产物现象
< 2Cu₂(OH)₂SO₄淡蓝色沉淀，Cu²⁺ 有剩余
= 2Cu(OH)₂蓝色沉淀，上清液无色
> 2Cu(OH)₂上清液仍无色
> 2 且浓[Cu(OH)₄]²⁻溶液变深蓝，固体减少

关键在于：每摩尔铜做成 Cu(OH)₂ 要 2 mol OH⁻，做成碱式硫酸铜只要 1 mol（代价是占用 SO₄²⁻）。所以碱不够时产物就变了。

加热分解
Cu(OH)₂ Δ → CuO↓ + H₂O

点「加热」点着酒精灯，约 55 °C 以上蓝色沉淀开始分解，接近沸点时很快，最后变成黑色 CuO。碱式硫酸铜同样分解，但硫酸根留在溶液里。

此过程不可逆：关掉火也不会变回蓝色，需要「重新实验」才会重置。

怎么操作

先选一组典型配比，或自己拖动浓度与体积滑块。改动任意参数即从头重做一次。

  • 加入顺序：先加 CuSO₄ 再加 NaOH（默认），或反过来。
  • 摇动烧杯：把已经沉降的沉淀重新扬起来。
  • 加热：开关酒精灯，观察沉淀由蓝转黑。
  • 重新实验：清空烧杯回到初始状态。
观察什么
  • 滴加 NaOH 时，液流附近先出现蓝色条带，再慢慢散开。
  • 沉淀是絮状胶体，会缓缓沉降，短时间内不会形成明显液面。
  • 碱不足时沉淀偏淡蓝绿色，那是碱式硫酸铜，与 Cu(OH)₂ 的天蓝色不同。
  • 下方的物质的量与判定随反应实时更新，可与画面互相印证。
模型说明

这不是播放动画，而是一个逐格计算的场模型：烧杯分成 56 × 92 的网格，每格记录各物种浓度，每帧依次做平流、扩散、局部反应与沉降。物质的量由场直接统计，所以读数与画面始终一致，且严格守恒。

溶液颜色用比尔-朗伯吸收加散射近似，吸收系数按观感调校，并非从真实吸收光谱计算；沉淀的絮状纹理、沉降速度同样做了视觉上的简化。
